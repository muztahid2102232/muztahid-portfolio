# Profile image

Drop your professional photograph here and name it `profile-placeholder.png`.

The hero reads this exact path:

```text
public/images/profile/profile-placeholder.png
```

Until the file exists, the hero renders a designed placeholder instead of a
broken image. No code changes are required after adding the file; restart the
dev server or rebuild the site so the server-side asset check picks it up.

Recommended: a vertical portrait, at least 800 × 1000 px, under 500 KB.
